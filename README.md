# CATALYZTER 80 Day Challenge PWA

فایل‌ها: index.html، style.css، app.js، manifest.json، sw.js و پوشه assets.

برای اجرای کامل PWA فایل‌ها را روی HTTPS یا GitHub Pages قرار بده. بار اول با اینترنت بازش کن تا Service Worker فایل‌ها را کش کند؛ اجرای مستقیم file:// سرویس‌ورکر و آفلاین واقعی ندارد. اطلاعات داخل localStorage همان مرورگر ذخیره می‌شود؛ برای پشتیبان از دکمه خروجی JSON استفاده کن. رتبه بر اساس روزهای تکمیل‌شده است. فونت سیستم جایگزین در حالت آفلاین هم کار می‌کند.
